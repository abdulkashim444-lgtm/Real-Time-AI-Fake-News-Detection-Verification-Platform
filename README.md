# 🔎 VeriLensAI

## 🧠 AI-Powered News Verification, Credibility Analysis & Misinformation Intelligence Platform

VeriLensAI is a next-generation news verification platform designed to analyze online content through linguistic analysis, source credibility assessment, evidence retrieval, fact-check matching, and explainable scoring. The platform combines interpretable machine learning with independent evidence and source signals to provide transparent verification results.

Built with React, TypeScript, TanStack Start, Tailwind CSS, Supabase, and Recharts, VeriLensAI provides an interactive workspace for analyzing news articles, reviewing claims, examining supporting or contradicting evidence, exploring source credibility, and monitoring verification analytics.

## 🌟 Vision

VeriLensAI aims to improve digital information trust by combining explainable machine learning, source analysis, independent evidence, and fact-checking signals into a transparent verification workflow. The platform emphasizes evidence-backed analysis and clearly communicates uncertainty when reliable verification signals are unavailable.

VeriLensAI demonstrates practical expertise in AI Engineering, NLP, Explainable AI, Full-Stack Development, Data Analytics, and Evidence-Based Information Verification.
